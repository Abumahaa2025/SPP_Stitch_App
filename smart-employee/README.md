# الموظف العقاري الذكي

تطبيق عربي مستقل لإدارة العقارات — واضح وسهل للمستخدم السعودي.

## التشغيل

```bash
cd smart-employee
npm install
npm run dev
```

ثم افتح الرابط المحلي من Vite.

## الدخول التجريبي

- أي جوال/بريد + كلمة مرور غير فارغة
- أو زر **دخول سريع للتجربة**

## ما يشمله MVP

- تسجيل دخول
- لوحة تحكم
- عقارات / عقود / حساسات / صيانة / مستأجرون / إعدادات
- حفظ محلي عبر `localStorage`

راجع `PRODUCT.md` لقرارات المنتج والهوية.
